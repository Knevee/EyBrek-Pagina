# EyBrek · Página del proyecto

Página de presentación de **EyBrek**, una aplicación de escritorio para Windows
que bloquea la pantalla de forma periódica y guía ejercicios visuales durante
la pausa, para que los descansos de la vista ocurran de verdad.

- **Página:** https://knevee.github.io/EyBrek-Pagina/
- **Descarga del proyecto completo** (código, instalador, manuales y
  presentación): en la sección [Releases](https://github.com/Knevee/EyBrek-Pagina/releases/latest).
- **Código fuente:** https://github.com/Knevee/EyBrek
